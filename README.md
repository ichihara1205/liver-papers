# 論文ライブラリ｜肝オープンオルガノイド・MASH・ABM

肝疾患（MASLD/MASH・肝オルガノイド・エージェントベースモデル）の論文を1本ずつ読み込み、次の内容をまとめた静的サイトです。

- 要旨の和訳
- 背景
- 成果
- limitation
- 自分の研究との接続
- 用語
- 図
- アニメーション

## 開き方

- **ローカル**：`index.html` をダブルクリックで開きます（`file://` のままで動きます）
- **GitHub Pages**：リポジトリのルートをそのまま公開します

ビルドは不要です。
外部への通信は Google Fonts、被引用数（OpenAlex）、新着検索（PubMed）だけで、オフラインでも本文は表示されます。

## 使い方のメモ

- **検索**
  - スペースで区切るとAND検索になります
  - 全角・半角、大文字・小文字は区別しません（ＭＡＳＨ＝MASH）
  - 用語集・手法名・研究ボードの内容も検索対象です
- **リンク**
  - 開いている論文・ビュー・絞り込み・検索語はURLの `#` 以降に入ります（例 `index.html#paper=48`、`#view=terms&q=TGF`）
  - そのURLを共有すれば同じ画面が開き、ブラウザの「戻る」で前の状態に戻れます
- **図**
  - 概念図・Method図はタップ／クリックで全画面表示になります
  - ピンチ・ホイールで拡大、ドラッグで移動できます
- **アニメーション**
  - ⏸ 一時停止、⏭ コマ送り、⏮ 前の場面、⛶ 大きく表示が使えます
  - OS の「視差効果を減らす」が有効なときは自動再生しません
- **⚙ 表示設定**
  - 文字サイズ、図の倍率、行間・余白、テーマ（自動／ライト／ダーク）、アニメーション（通常／遅め／オフ）を切り替えられます
  - 設定は端末に保存されます
- **端末間の移動**
  - ⚙ またはページ下部の「JSONで書き出す／読み込む」で、既読・★・メモを PC とスマホの間で移せます

## 論文を追加する

[ADDING.md](ADDING.md) を参照してください。
要約すると、`papers/NN.js` を1ファイル追加し、`index.html` の一覧に1行足して、`node scripts/check.mjs` を実行します。

## 構成

| パス | 役割 |
|---|---|
| `index.html` | CSS・HTML・スクリプト読み込み一覧 |
| `js/core.js` | テーマ・アイコン・手法の定義、論文の登録API `LP` |
| `js/cinema.js` | アニメーション再生エンジン（CinemaKit）と共通部品 `GLYPH` |
| `js/catinfo.js` | 用語カテゴリ |
| `papers/NN.js` | 論文1本ぶんのデータ |
| `js/app.js` | 描画・検索・フィルタ・各ビュー |
| `scripts/check.mjs` | データ検証（GitHub Actions でも実行） |

## 端末内データ

次のデータはブラウザの localStorage（`liverPapers_userData_v1`）に保存され、JSON で書き出し・読み込みできます。

- 既読
- お気に入り
- メモ
- 研究ボードのチェック

表示設定は `liverPapers_display_v1` に保存されます。
